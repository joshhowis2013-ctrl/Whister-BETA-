Whister 2.0 Beta 1 Is Here

Whister 2.0 Beta 1 is now available for Windows 10 and 11 (64-bit). This is the first public build of the rebuilt browser. It is an early pre-release: expect rough edges, back up anything important, and test it in a virtual machine before considering regular use.

What is in Beta 1

  • A rebuilt Chromium browser. Chromium 157.0.8084.0 is the foundation for this beta.
  • A Whister new tab. Search, time, appearance choices, and a selectable search engine are built into the browser.
  • Whister settings. Separate areas for search, appearance, startup, privacy, autofill, languages, downloads, and browser information.
  • A Windows installer. Installs per-user, creates Start menu and desktop shortcuts, and includes an uninstaller.

Known issues

This is a pre-release, and we want to be clear about its current limits:

  • Do not make this your default browser yet. Stability testing is still in progress.
  • The first-run welcome may still show Chromium’s stock screen in this build.
  • Some published builds may crash when opening the custom new tab or changing the search engine. A corrected build is being tested.
  • uBlock Origin Lite may not install automatically in this package. You can install it from the official Chrome Web Store listing.
  • Some browser pages still use Chromium’s standard interface.
  • Whister does not update itself; download future builds manually from the GitHub release page.
  • Windows only for now.

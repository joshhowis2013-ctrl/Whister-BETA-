Whister Beta 3 is in the works

Work is underway on Whister 2.0 Beta 3. We are continuing to improve the browser and test changes before sharing the next build. This is a development update, not a release announcement, and there is no release date to share yet.

The custom Whister Blocker is going away

The custom Whister Blocker is planned to be removed in Beta 3. Whister will continue to include uBlock Origin as its built-in content blocker. The change is about removing Whister's separate blocker, not removing content blocking from the browser.

Maintaining two blockers led to overlapping filtering and compatibility issues on some websites. When both systems evaluate the same page, it can be harder to identify which rule caused a site element or request to fail. Focusing on one blocker should make the setup simpler to understand and troubleshoot.

How the blockers compare

This table describes the current plan for Beta 3. It compares Whister's custom blocker with uBlock Origin as it is bundled with Whister; it does not promise that every site will work perfectly.

Planned content-blocking setup in Whister Beta 3
Area Whister Blocker uBlock Origin
What it is Whister's separate, custom content blocker. An independently maintained content-blocking extension included with Whister.
Beta 3 plan Planned to be removed. Remains included as Whister's built-in content blocker.
Where to manage it Its separate Whister controls and settings. The extension popup and dashboard, including filter-list and user-rule settings.
Why the change Running it alongside another blocker created overlapping filtering and compatibility issues. Using it on its own avoids maintaining two independent blockers on the same pages.
What to expect Its separate settings will no longer be part of the planned Beta 3 setup. It can still block content, but some sites may need per-site troubleshooting or rule adjustments.

What this means for uBlock Origin

  • uBlock Origin remains included with Whister; the planned change does not remove it.
  • You can manage filtering through its toolbar popup and dashboard rather than a separate Whister Blocker page.
  • Filter lists and user rules remain adjustable, but adding more rules can sometimes cause site compatibility problems.
  • If a site breaks, use the steps in our uBlock Origin guide to troubleshoot it.

What is still in progress

Beta 3 is being developed and tested. This post covers the blocker direction only; it is not a complete feature list, and other details may change before a release. We will share an update when there is a build ready to announce.

The previous Beta 2 article describes that release's custom blocker. That description is historical and does not change the planned Beta 3 direction.

Beta 3 status

There is no release date to share yet. Please treat the blocker transition and other plans as tentative until they appear in a published Beta 3 build.

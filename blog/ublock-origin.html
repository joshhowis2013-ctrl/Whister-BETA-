Using uBlock Origin in Whister

Whister includes uBlock Origin as its built-in content blocker. It uses filter lists and your own rules to block many unwanted network requests and hide page elements, which can make browsing cleaner and sometimes faster. As work continues on Beta 3, the separate custom Whister Blocker is being retired; uBlock Origin will remain included.

What is changing in Beta 3?

Whister previously had its own blocker alongside uBlock Origin. Running both could make them apply overlapping rules and cause compatibility problems on some sites. The plan for Beta 3 is to remove the custom Whister Blocker and its separate controls, leaving uBlock Origin as Whister's built-in content blocker.

Beta 3 is still in development. This is a progress update, not a release announcement; details may change as testing continues.

Open the controls

Select the uBlock Origin icon in Whister's toolbar to open its popup. The popup provides the current site's controls; use its dashboard button to manage filter lists and other settings.

Choose filter lists carefully

Filter lists are collections of rules maintained for different kinds of content. The defaults are a good starting point. You can review or change them in the dashboard's Filter lists tab. Adding more lists is optional, and overlapping or aggressive rules can cause parts of a site to stop working.

If a site does not work

  1. Open the uBlock Origin popup on that site.
  2. Use the large power button to pause filtering for the current site, then reload the page.
  3. If that fixes the issue, turn filtering back on and adjust site-specific settings or report the broken page to the relevant filter-list maintainers.

Pausing filtering is a troubleshooting step, not a guarantee that the site is safe. Only allow sites you trust.

What it does not do

Content blocking is one part of safer browsing, not a promise of anonymity or complete protection. uBlock Origin is not a VPN or antivirus, and websites you visit still receive requests from your browser. Keep Whister and its extensions up to date, and use care with downloads and links.

For more about the project, visit the official uBlock Origin website.

Getting Started with Whister 2.0 Beta 1

Thanks for trying Whister. Beta 1 is an early Windows pre-release, so test it in a virtual machine or on a non-critical profile. It is not ready to be your default browser.

1. Download and verify

Get Whister-Beta1-Setup.exe from the official 2.0 release page.

For the published installer, the SHA-256 is:

9BE6C43D87E994D6ADC5156137B8422837B51C1777C8B151115F1CEF9C0B875C

In PowerShell, you can check the file with Get-FileHash .\Whister-Beta1-Setup.exe -Algorithm SHA256. Only continue if the result matches.

2. Install

Run the installer and follow its prompts. It installs for your Windows account and creates Start menu and desktop shortcuts. If Windows displays a security warning, make sure the file came from the release page above before choosing to continue.

3. First launch

This beta may show Chromium’s stock welcome screen on first launch. Continue through it if it appears. You can open Whister settings later from the address bar at chrome://whister-settings.

The new tab includes a search provider selector. In this published build, changing the search engine can crash Whister; keep the current selection until a corrected build is posted. The newer background and widget customizer is not included in this installer yet.

4. Keep the beta in perspective

  • Use a virtual machine for testing and avoid sensitive accounts or important browsing.
  • The new-tab and search-engine crash fixes are still being tested. If either crashes, stop testing that feature and send us the crash report.
  • uBlock Origin Lite may need to be installed manually from its official Chrome Web Store listing.
  • Some pages still use Chromium’s standard interface.
  • Whister does not update itself yet. Check the blog or release page for newer builds.
  • If a tab or the browser crashes, note what you were doing and share the crash report with us.

Thanks for helping us test Whister 2.0 Beta 1. Your reports help us make the next build safer and more reliable.

Questions

Frequently asked questions

Is Whister free?

Yes. Whister is free to download and use, and the source is on GitHub. There is no account and no advertising.

Can I import my data from Chrome or Brave?

Because Whister is built on Chromium, you can import bookmarks, history and passwords from other browsers using the browser’s standard import tool.

How do Bangs work?

Start a search with a shortcut such as !yt or !gh and the search goes straight to that site instead of a general search page. The demo on this page shows the idea.

Which systems are supported?

Windows 10 and 11 (64-bit) for now. macOS and Linux builds are planned for later.

Does Whister update itself?

Not yet. For now you install new builds from this site. Check the blog for release news.
